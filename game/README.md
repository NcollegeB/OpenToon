# OpenToon game source

This directory contains the modified game client, district server, UberDOG,
Astron configuration, networking schemas, platform scripts, and development
tools used by OpenToon.

Read the repository-level [`README.md`](../README.md) for dependency setup,
server startup, platform notes, the source tree, player-data locations, file
types, security guidance, and launcher builds.

This source is based on [Open Toontown](https://github.com/open-toontown/open-toontown).
The upstream source remains under the BSD 3-Clause License in
[`LICENSE`](LICENSE). OpenToon changes are maintained by NcollegeB.

Resources, native runtimes, server databases, logs, and compiled executables
are deliberately not distributed in the public source repository.
